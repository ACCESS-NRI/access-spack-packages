# UM Spack Package

This directory contains the UM spack package. This works with UM version 13 and uses the [UmBasePackage](../../build_systems/README.md)

## access3 variant

When _False_, this package installs _um-atmos.exe_

When _True_, the package installs _libum-atmos.a_

_um-recon.exe_ is installed in both cases.
